# Finlance (Monorepo)

Plataforma completa de gestão financeira e de perfil para freelancers.

## Estrutura do Projeto

- **`backend-api`** — API REST construída em Java e Spring Boot.
- **`frontend-web`** — Interface do usuário construída em Angular (em desenvolvimento).
